# Jasper Task Manager

A simple task manager built with React as part of my journey learning React and frontend development.

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Clean and simple user interface
- Responsive layout

## Built With

- React
- JavaScript
- CSS
- Vite

## What I Learned

While building this project, I practiced:

- React components
- Props
- State management with `useState`
- Event handling
- Conditional rendering
- Passing functions between components
- Basic CSS styling
